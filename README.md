# Kalki Hema Priya R — Resume-Based Portfolio

This portfolio has been updated using the details from the supplied resume.

## Included
- `index.html` — complete portfolio page
- `style.css` — responsive dark-themed styling
- `script.js` — mobile menu, scroll reveal, active navigation, dynamic year
- `assets/profile.jpg` — profile photo
- `resume/Kalki-Hema-Priya-Resume.pdf` — supplied resume PDF

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Click **Download Resume** to open/download the supplied resume PDF.

## Portfolio sections
Home, About, Technical Skills, Work Experience, Featured Projects, Industry Exposure, Education & Certifications, and Contact.

## Resume-aligned content
The project names, technology lists, work experience, education, certifications, and industry exposure are based on the supplied resume.
